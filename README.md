# Portafolio Santisarm

Portafolio web de **Santiago Sarmiento (SantiSarm)**, estudiante de Ingeniería Multimedia · Universidad Simón Bolívar, Cúcuta.

🌐 **Ver la página:** https://santisarm0607.github.io/

## Secciones

| Página | Qué tiene |
| --- | --- |
| `index.html` | Inicio: presentación, habilidades y contacto rápido |
| `blog.html` | Portafolio: 7 proyectos de diseño con filtros y visor de imágenes |
| `juegos.html` | **Arcade**: una nave viaja al planeta de cada juego |
| `cosmoball.html` | COSMOBALL, ping-pong espacial (1 jugador, 2 jugadores o en línea) |
| `futbol.html` | Galaxy Gol, fútbol 4 contra 4 de alienígenas (contra Zorp, 2 jugadores o en línea) |
| `contacto.html` | Formulario de contacto |

Los juegos están en `juegos/` y tienen su propio repositorio:
[cosmoball](https://github.com/santisarm0607/cosmoball) · [galaxy-gol](https://github.com/santisarm0607/galaxy-gol).

Hecho con HTML5, CSS3 y JavaScript (Canvas, Web Audio, LocalStorage, WebRTC con PeerJS). Bootstrap 5 solo en el formulario de contacto.
Cómo está hecho todo: ver `NOTAS.md`.
