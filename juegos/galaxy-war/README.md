# 🚀 GALAXY WAR

Juego web 3D de combate espacial hecho con **Three.js r128**, HTML, CSS y JavaScript.
Autor: **David Santiago Sarmiento Salguero (SantiSarm)** · Ingeniería Multimedia, Universidad Simón Bolívar (Cúcuta).

▶ **Jugar:** https://santisarm0607.github.io/galaxy-war/

## Qué tiene
- Campaña con 2 bandos (Militares y Alienígenas) y 8 jefes.
- Cápsulas de poder, mejoras de nave por nivel, eventos (lluvia de meteoritos, emboscadas) y logros.
- 🏁 **Carrera galáctica**: 3 vueltas por un circuito de 14 anillos, puntos por anillos y enemigos derribados.
- Modelos 3D y sonidos generados por código (sin archivos externos). Funciona en PC y celular.

## Controles (PC)
| Tecla | Acción |
|---|---|
| Ratón | Girar y apuntar |
| Flechas · A / D | Moverse a los lados y subir / bajar (sin girar) |
| W / S | Acelerar / frenar |
| Clic · Espacio | Disparar |
| Clic derecho · E · Q | Misil |
| Shift | Esquiva |
| ESC · P | Pausa |

En celular: joystick izquierdo para moverse y arrastrar el dedo en el lado derecho para girar.

## Estructura
```
index.html      → menús, HUD y pantallas
css/style.css   → estilos
js/script.js    → lógica del juego
```
